# Revisão geral do portfólio

**Data:** 26/10/2026
**Escopo:** seis páginas HTML, CSS, JavaScript, imagens, links, formulários, rodapé e versão publicada no GitHub Pages.
**Objetivo:** registrar o que já funciona, o que está incompleto e o que deve ser priorizado para tornar o portfólio mais confiável, autoral e convincente.

## Resumo executivo

O projeto está publicado e as seis rotas principais respondem com sucesso. A identidade escura com ciano, o logotipo colorido e o layout adaptado para celular dão uma base visual reconhecível. A versão móvel da página inicial foi conferida em uma largura de 390 px e não apresentou rolagem horizontal.

Ainda não está pronto para funcionar como portfólio profissional: a página de projetos está marcada como “Em desenvolvimento”; os cartões de projetos e certificados usam arquivos de imagem que não existem; há destinos de links provisórios ou inexistentes; o formulário redireciona para um endereço de exemplo; e o site publicado registra erros de JavaScript em todas as páginas. O rodapé também contém links provisórios.

Para parecer um trabalho pessoal, excepcional e feito por alguém com domínio do assunto, a prioridade é substituir os elementos genéricos por evidências reais: projetos autorais, decisões explicadas, resultados verificáveis, voz própria e uma apresentação que mostre a pessoa por trás da marca. Efeitos visuais, barras de habilidade e adjetivos não substituem esse tipo de prova.

## Evidências e limites da revisão

- As seis páginas principais (`index.html`, `about.html`, `services.html`, `projects.html`, `certificates.html` e `contact.html`) responderam com HTTP 200 no GitHub Pages.
- O navegador registrou erros de JavaScript em todas as rotas testadas e erros 404 para imagens referenciadas que não estão no repositório.
- As seis páginas foram conferidas em uma largura móvel de 390 px; nenhuma apresentou rolagem horizontal. As páginas de certificados e sobre mantêm imagens quebradas também nessa largura.
- O clique nos filtros de habilidade e de serviço foi testado no navegador e reproduziu a interferência descrita acima.
- O envio do formulário não foi testado para evitar enviar uma mensagem real ou acionar um serviço externo.
- Esta revisão registra achados e recomendações; não altera funcionalidades, conteúdo nem configuração de publicação.

## Ordem sugerida para deixar o portfólio pronto

1. Corrigir erros de JavaScript e filtros, e remover os destinos de exemplo dos contatos/formulário.
2. Decidir quais projetos e certificados são reais; incluir arquivos e provas correspondentes e corrigir/remover os links sem destino.
3. Completar `projects.html`, eliminar duplicações em `about.html` e revisar a hierarquia de títulos.
4. Completar o rodapé, o favicon, os metadados e os estados acessíveis do menu e dos filtros.
5. Refinar a identidade visual com tipografia, narrativa e estudos de caso próprios; reduzir elementos genéricos quando não acrescentarem significado.
6. Adicionar documentação, testes básicos e limpar os metadados de `node_modules` do repositório.
